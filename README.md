# FORGE — Athlete Planner

Mobile-first PWA prototype for planning mixed training: running, strength, HYROX, cycling, swimming and recovery.

## Run locally
Open `index.html` in a local web server.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Open the generated Pages URL on iPhone.
5. Safari → Share → Add to Home Screen.
